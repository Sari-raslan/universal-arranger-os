# UAOS Manual Delivery Readiness

Status: MANUAL_DELIVERY_READINESS_READY

Allowed delivery after owner review:
- metadata reports
- dashboards
- documentation
- review packs
- planning documents
- support replies

Forbidden delivery:
- keyboard binary output
- SET/PCM/STY/KMP/KSF writer output
- decoded samples
- PCM payload parse results
- PA3X-ready packages.
