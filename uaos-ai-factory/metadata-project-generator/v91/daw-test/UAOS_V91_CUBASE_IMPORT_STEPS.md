3. Import `../../v71/midi/UAOS_V71_REAL_MIDI_EXPORT_FOUNDATION.mid`.
4. Import `../../v81/midi/UAOS_V81_SECTION_BASED_REAL_MIDI_EXPORT.mid`.
5. Import `../../v82/midi/UAOS_V82_MULTITRACK_ARRANGEMENT_EXPORT.mid`.
6. Confirm tracks, tempo, sections, and note events appear.
7. Listen for drums, bass, chords, pad, melody guide, section flow, tempo feel, and DAW import issues.
