# UAOS Sound Library Factory Validation Rules

The validator checks catalog, pack count, preset count, schemas, manifests, no commercial or proprietary source paths, no proprietary extraction claims, no KORG files, no USB path, no PA3X load, no App.jsx touch, no React integration, no deploy/payment, no compatibility claim, no PA3X-ready claim, no huge binary junk, and optional synthetic WAV labeling if files exist.
