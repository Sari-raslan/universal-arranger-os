# UAOS Maqam-Aware Arranger Rules - Run 003

Status: READY

## Rules

- Treat maqam as melodic behavior, not only note collection.
- Use characteristic tones for phrase anchors.
- Use ornament density based on section energy.
- Prefer emotional sustain in intro and ending.
- Prefer slides and portamento in transitions.
- Prefer marcato or tremolo in chorus or cinematic peak sections.
- Keep quarter-tone information as metadata only.
- Keep output as arrangement plan JSON until owner approves deeper implementation.

## Section Defaults

- Intro: low to medium energy, introduce maqam identity.
- Verse: clear motif, restrained ornament density.
- Chorus: higher energy, fuller instrument support.
- Bridge: contrast through register or texture.
- Fill: short transition with ornament or rhythmic motion.
- Ending: emotional sustain or final cadence behavior.
