# UAOS Jobcenter Monitor Design Sync

Diese lokale Monitor-Quelle nutzt dasselbe visuelle System wie die neue Jobcenter-PDF und die neue Präsentation.

## Manuelle Veröffentlichung

Falls automatische Veröffentlichung nicht möglich ist:

1. Vercel öffnen.
2. Projekt `uaos-jobcenter-monitor` auswählen.
3. Diese Quelle als Projektwurzel verwenden: `uaos-ai-factory/jobcenter-monitor-design-sync`.
4. Ausgabeordner: `public`.
5. Ohne Build-Befehl veröffentlichen.
6. Danach prüfen:
   - https://uaos-jobcenter-monitor.vercel.app/jobcenter/
   - https://uaos-jobcenter-monitor.vercel.app/status/

## Gestaltung

- Dunkler professioneller Hintergrund
- Akzentfarbe Cyan und gelber Prüfmarker
- Karten, Tabellen und Kopfbereiche wie in PDF und Präsentation
- Deutsche Inhalte ohne private oder persönliche Links
