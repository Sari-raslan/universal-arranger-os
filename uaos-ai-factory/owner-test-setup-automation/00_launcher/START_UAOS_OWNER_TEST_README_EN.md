# Start UAOS Owner Test

Double-click `START_UAOS_OWNER_TEST.cmd`.

It will run a local build, start the local preview server when available, open the owner dashboard, and open the local app URL.

Local URL: `http://127.0.0.1:4173/universal-arranger-os/`

Manual fallback: Run START_UAOS_OWNER_TEST.cmd. If the browser does not open, run npm run preview -- --host 127.0.0.1 --port 4173 from the React app folder, then open the local URL.

Safety: no deploy, no push, no USB, no PA3X load, no payment activation, KORG Writer blocked.
