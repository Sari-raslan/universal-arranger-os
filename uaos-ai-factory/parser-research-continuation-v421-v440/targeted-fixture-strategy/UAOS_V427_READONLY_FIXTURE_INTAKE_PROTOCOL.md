# UAOS V427 Read-only Fixture Intake Protocol

Minimum safe metadata:
- File name label chosen by owner.
- Byte size.
- SHA-256 hash.
- Optional first-header summary if owner approves header-only inspection.
- Owner notes about known sections/tracks.

Hash-only option:
- Record hash and byte size only.

Header-only option:
- Inspect limited header bytes only if owner approves.

Policies:
- No content copying.
- No sample extraction.
- No modification.
- No redistribution.
