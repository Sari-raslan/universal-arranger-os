# UAOS V424 Review Boundaries And Safety

Reviewer may review:
- Schema and confidence reasoning.
- Evidence references.
- Fixture intake protocol.
- Blocker map.

Reviewer must not:
- Request proprietary content extraction.
- Copy samples.
- Modify fixtures.
- Implement a real writer.
- Create native keyboard output.
- Write USB or load PA3X.
- Make compatibility or PA3X readiness claims.
