# UAOS PC Workstation MVP V1 Product Scope

PC_ONLY / UAOS_FORMAT / TEST_UNVERIFIED / NOT_FOR_PA3X_LOAD / NOT_FOR_USB_TRANSFER

This MVP is local PC software only. It has no hardware dependency and makes no PA3X-ready or KORG compatibility claim.

Core scope:
- Create, open, and save a UAOS project package for PC workflow.
- Write a UAOS style file using UAOS_FORMAT metadata.
- Manage UAOS library metadata for Arabic strings and arranger tracks.
- Preview a synthetic Arabic strings library structure using generated metadata only.
- Export a simple MIDI preview for PC/DAW review only.

Blocked:
- Real KORG .SET/.PRF writing.
- USB transfer or copy.
- PA3X keyboard loading.
- Proprietary sample copying.
- Deployment or payment workflow.
