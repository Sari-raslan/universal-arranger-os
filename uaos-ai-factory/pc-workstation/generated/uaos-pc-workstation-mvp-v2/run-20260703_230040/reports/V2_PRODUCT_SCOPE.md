# UAOS PC Workstation MVP V2 Product Scope

PC_ONLY / UAOS_FORMAT / TEST_UNVERIFIED / NOT_FOR_PA3X_LOAD / NOT_FOR_USB_TRANSFER / NOT_COMPATIBILITY_VERIFIED

V2 goal: the owner can open one local HTML file and understand the project, style, Arabic strings library, MIDI preview, writer outputs, validation status, and next product steps.

This remains PC software only. It does not create a real keyboard load package, does not write .SET/.PRF files, does not use USB, and makes no hardware compatibility claim.

Improvements over V1:
- Arabic-first local app with clearer sections.
- Dedicated style viewer data.
- Dedicated library viewer data.
- MIDI preview instructions for DAW review.
- Writer V2 outputs with richer sections, track roles, library references, and safety labels.
