# UAOS PC Workstation MVP V4 Product Scope

PC_ONLY / UAOS_FORMAT / TEST_UNVERIFIED / NOT_FOR_PA3X_LOAD / NOT_FOR_USB_TRANSFER / NOT_COMPATIBILITY_VERIFIED

V4 adds import/regenerate workflow. The browser app imports Project JSON, Style JSON, and Library Binding JSON with file picker inputs, previews the imported data, and exports the current imported state. Python writer V4 consumes edited JSON from the local input folder, regenerates UAOS project/style/library files, and regenerates a MIDI preview from imported chords. This remains PC-only and not hardware-ready.
