# UAOS PC Workstation MVP V3 Product Scope

PC_ONLY / UAOS_FORMAT / TEST_UNVERIFIED / NOT_FOR_PA3X_LOAD / NOT_FOR_USB_TRANSFER / NOT_COMPATIBILITY_VERIFIED

V3 is a local browser editor. The owner can edit project name, tempo, chords, section bars, track names, and the Arabic strings preset, then export edited JSON locally from browser download buttons. Python writer V3 generates matching UAOS_FORMAT files from the default editor state. No PA3X, USB, hardware, deployment, payment, or proprietary sample workflow is included.
