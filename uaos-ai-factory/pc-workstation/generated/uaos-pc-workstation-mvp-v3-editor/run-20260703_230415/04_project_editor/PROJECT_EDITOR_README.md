# Project Editor

PC_ONLY / UAOS_FORMAT / TEST_UNVERIFIED / NOT_FOR_PA3X_LOAD / NOT_FOR_USB_TRANSFER / NOT_COMPATIBILITY_VERIFIED

The owner can edit project name, style name, tempo, meter, and chord progression. Export buttons use browser Blob downloads to save JSON locally. Future V4 can import edited JSON into the Python writer. This is PC-only and not a hardware package.
