# UAOS Internal Player V11

This local browser player adds a synthetic preview workflow to the stable PC workstation app.

- Uses WebAudio oscillators only.
- Includes project, style, tempo, meter, chords, sections, tracks, and selected Arabic strings preset.
- Keeps the existing MIDI preview link for DAW or Cubase use.
- Does not use samples, external audio, proprietary libraries, USB transfer, or hardware loading.

Safety status: PC_ONLY, SYNTHETIC_PREVIEW_ONLY, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.
