# محرر مشروع UAOS V13

هذا المحرر صفحة محلية مستقلة داخل المتصفح لتعديل بيانات مشروع UAOS PC Workstation.

علامات السلامة:

- PC_ONLY
- UAOS_FORMAT
- TEST_UNVERIFIED
- NOT_FOR_PA3X_LOAD
- NOT_FOR_USB_TRANSFER
- NOT_COMPATIBILITY_VERIFIED

التصدير:

- Project JSON
- Style JSON
- Full Session JSON

ملفات JSON الناتجة مخصصة لمسار UAOS PC writer فقط. ليست باكج كيبورد، وليست للتحميل على جهاز، وليست للنقل عبر وسيط خارجي.
