# UAOS Project Editor V13

This editor is a standalone local browser page for editing UAOS PC workstation project metadata.

Safety labels:

- PC_ONLY
- UAOS_FORMAT
- TEST_UNVERIFIED
- NOT_FOR_PA3X_LOAD
- NOT_FOR_USB_TRANSFER
- NOT_COMPATIBILITY_VERIFIED

Exports:

- Project JSON
- Style JSON
- Full Session JSON

Exported JSON is for the UAOS PC writer workflow only. It is not a keyboard package, not for keyboard load, and not for transfer media.
