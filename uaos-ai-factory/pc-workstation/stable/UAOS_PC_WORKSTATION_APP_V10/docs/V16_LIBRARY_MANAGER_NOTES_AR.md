# ملاحظات مدير المكتبة V16

إصدار V16 يحسن مسار المكتبة داخل تطبيق الكمبيوتر من خلال بيانات بريستات الوتريات العربية، بيانات articulations، عرض التصنيفات، اختيار ربط التراكات، وتصدير JSON.

لا توجد عينات صوتية. قسم عينات المستخدم المستقبلية مجرد placeholder فقط لمواد يملكها المستخدم ومرخصة لاحقا.

علامات السلامة: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, METADATA_ONLY, NO_SAMPLES_INCLUDED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.
