# V15 Internal Audio Player Notes

V15 improves the internal preview player with separate synthetic modes for full pattern, drums pulse, bass guide, chord pad, Arabic strings guide, and melody guide.

It is a PC-only preview tool and keeps the existing MIDI file link for DAW use.
