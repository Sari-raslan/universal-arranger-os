# Start Here - UAOS PC Workstation V22

Open `START_UAOS_PC_WORKSTATION_V22.cmd`.

V22 is now the recommended main app. Older pages are support tools only.

Use the single workstation interface for Project, Arrangement, Style, Library, Player, Writer, Files, Safety, and Help.

This is PC-only software. It does not write to removable media, does not load anything to hardware, and does not include sample libraries.

To generate local writer outputs, use the Writer panel and run `writer\RUN_WRITER_V17.cmd` manually from Windows.

Troubleshooting: if browser audio does not start, click inside the page once, then press Play again.

Safety labels: PC_ONLY / UAOS_FORMAT / TEST_UNVERIFIED / NOT_FOR_PA3X_LOAD / NOT_FOR_USB_TRANSFER / NOT_COMPATIBILITY_VERIFIED
