# Start Here - UAOS PC Workstation V21

Open `START_UAOS_PC_WORKSTATION_V21.cmd`.

V21 is now the main recommended interface. Use the left sidebar to move through the workstation panels.

1. Edit the project in `Project`.
2. Edit the arrangement in `Arrangement` and `Style Editor`.
3. Choose Arabic strings metadata in `Library`.
4. Preview the sketch in `Player`.
5. Run `Writer` manually from the Writer panel or `writer\RUN_WRITER_V17.cmd`.
6. Open the MIDI in Cubase.

Important: this is PC-only software. It does not claim PA3X readiness, does not write to USB, does not load anything to hardware, and does not include proprietary samples. The player uses only synthetic WebAudio oscillator preview.
