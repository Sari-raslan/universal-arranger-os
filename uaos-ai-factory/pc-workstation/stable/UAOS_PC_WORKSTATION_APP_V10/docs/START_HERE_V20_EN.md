# Start Here V20

Open `START_UAOS_PC_WORKSTATION_V20.cmd` or open `UAOS_PC_WORKSTATION_APP_V20.html` directly.

V20 is the new main app experience. It is a local browser app with project editing, style section editing, library preset selection, WebAudio synthetic preview, and JSON export from one page.

To generate local writer files, run `writer\RUN_WRITER_V17.cmd` yourself from Windows. Open MIDI output in Cubase from the local MIDI or writer output folders.

This is PC-only. It is not a PA3X SET, does not write to USB, and does not load anything to a keyboard.
