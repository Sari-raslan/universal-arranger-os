# Start Here V19

Open `START_UAOS_PC_WORKSTATION.cmd`, then open Daily Workflow V19.

Daily order:

1. Open Home.
2. Open Project Editor and edit the project.
3. Open Style Section Editor and edit sections.
4. Open Library Manager and choose Arabic strings.
5. Open Internal Player and listen to synthetic preview.
6. Run `writer/RUN_WRITER_V17.cmd`.
7. Open the generated MIDI in Cubase or another DAW.
8. Open Self Check V18.

This is a PC workstation workflow only. It is not a keyboard package. No transfer media. No hardware load.
