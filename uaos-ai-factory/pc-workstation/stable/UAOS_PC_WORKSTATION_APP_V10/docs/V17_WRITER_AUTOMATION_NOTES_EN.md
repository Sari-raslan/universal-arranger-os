# V17 Writer Automation Notes

V17 adds a local Python writer and a Windows command runner. The writer reads `writer_input_default_v17.json` and writes PC-only UAOS project, style, library binding, manifest, run log, and synthetic MIDI output into `writer/generated_v17_outputs`.

Safety labels: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.

No external output path, no transfer media, no hardware package, no proprietary samples.
