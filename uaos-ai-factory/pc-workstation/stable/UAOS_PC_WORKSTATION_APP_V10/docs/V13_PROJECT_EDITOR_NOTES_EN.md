# V13 Project Editor Notes

V13 adds a local browser project editor to the stable PC app. The owner can adjust project and style metadata, then export JSON for the PC-only UAOS writer workflow.

No server is required. No external libraries are used. The page exports JSON with browser Blob downloads.

Safety labels: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.
