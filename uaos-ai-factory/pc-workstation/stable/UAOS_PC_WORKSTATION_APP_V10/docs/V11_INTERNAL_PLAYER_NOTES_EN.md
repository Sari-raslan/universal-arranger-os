# V11 Internal Player Notes

V11 adds a browser-based internal preview player to the stable PC app folder. It is intended for quick arrangement checks before opening the MIDI file in a DAW.

The preview is deliberately synthetic: it uses WebAudio oscillators and gain envelopes only. It does not contain samples, copyrighted melody, proprietary library material, or hardware-specific export claims.

Status: PC software only. The app is not a keyboard package and is not verified for hardware loading or USB transfer.
