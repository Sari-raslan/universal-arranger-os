# ابدأ من هنا - UAOS PC Workstation V23

افتح `START_UAOS_PC_WORKSTATION_V23.cmd`.

V23 هو البرنامج الرئيسي المقترح الآن، و V22 وما قبله نسخ دعم فقط.

استخدم لوحة `Daily Workflow` للعمل اليومي:

1. Project
2. Style
3. Library
4. Preview
5. Writer
6. MIDI/Cubase

قبل اختبار المالك، افتح `Self-Test` واضغط `Run UI Self-Test`.

هذا برنامج PC فقط. لا USB، لا تحميل PA3X، لا عينات خاصة، ولا تشغيل تلقائي لملفات CMD من المتصفح.
