# Owner Daily Workflow V19

Use this sequence for daily work:

1. Open `START_UAOS_PC_WORKSTATION.cmd`.
2. Open `dash/UAOS_PC_WORKSTATION_DAILY_WORKFLOW_V19.html`.
3. Edit project details in Project Editor V13.
4. Edit arrangement sections in Style Section Editor V14.
5. Choose Arabic strings metadata in Library Manager V16.
6. Preview with Internal Audio Player V15.
7. Run Writer V17.
8. Open `writer/generated_v17_outputs/SARI_ARABIC_POP_ORIENTAL_BALLAD_V17.mid` in Cubase or a DAW.
9. Open Self Check V18.

PC-only. Not for keyboard load. Not for transfer media.
