# ملاحظات محرر المشروع V13

إصدار V13 يضيف محرر مشروع محلي داخل المتصفح ضمن تطبيق الكمبيوتر المستقر. يمكن للمالك تعديل بيانات المشروع والستايل ثم تصدير JSON لمسار UAOS PC writer فقط.

لا يحتاج إلى سيرفر. لا يستخدم مكتبات خارجية. التصدير يتم من المتصفح باستخدام Blob download.

علامات السلامة: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.
