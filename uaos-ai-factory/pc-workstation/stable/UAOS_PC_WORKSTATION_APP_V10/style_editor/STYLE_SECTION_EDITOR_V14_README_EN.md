# UAOS Style Section Editor V14

Standalone local browser editor for UAOS PC workstation style sections and track maps.

Safety labels: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.

Exports are JSON files for the UAOS PC workflow only. No hardware files, no keyboard package, no transfer media.
