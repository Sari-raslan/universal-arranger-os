# مدير مكتبة UAOS V16

مدير محلي داخل المتصفح لربط بيانات مكتبة UAOS PC Workstation.

علامات السلامة: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, METADATA_ONLY, NO_SAMPLES_INCLUDED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.

هذه الحزمة تحتوي على بيانات بريستات، أسماء articulations، تصنيفات، وتصدير track mappings فقط. لا تحتوي على عينات صوت حقيقية ولا محتوى مكتبات مملوك.
