# UAOS Library Manager V16

Metadata-only local browser manager for UAOS PC workstation library bindings.

Safety labels: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, METADATA_ONLY, NO_SAMPLES_INCLUDED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.

This package includes preset metadata, articulation names, categories, and track mapping exports only. It includes no real audio samples and no proprietary library content.
