# UAOS PC Workstation V29 Electron Smoke Test

This folder contains the local Electron wrapper for the owner beta workstation.

Use `SMOKE_TEST_ELECTRON_V29.cmd` to check that the local package files exist. It does not launch Electron.

Use `START_ELECTRON_LOCAL_V29.cmd` to show the local executable path and manual launch instructions. It does not install, build, deploy, create an installer, copy files outside the repo, or perform hardware actions.

Expected local package folder:

`dist-local\win-unpacked`

Expected executable:

`dist-local\win-unpacked\UAOS PC Workstation Owner Beta.exe`
