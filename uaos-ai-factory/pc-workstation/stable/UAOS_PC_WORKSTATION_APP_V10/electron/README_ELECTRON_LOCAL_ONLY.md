# UAOS PC Workstation V12 Electron Scaffold

This folder is a local wrapper scaffold only.

Safety labels:

- PC_ONLY
- UAOS_FORMAT
- TEST_UNVERIFIED
- NOT_FOR_PA3X_LOAD
- NOT_FOR_USB_TRANSFER
- NOT_COMPATIBILITY_VERIFIED

What this run did:

- Created Electron scaffold files.
- Pointed the wrapper at the existing local `../UAOS_PC_WORKSTATION_HOME.html`.
- Did not install dependencies.
- Did not execute Electron.
- Did not build an installer.
- Did not deploy anything.
- Did not copy anything outside the repository.

How the owner can later test manually:

1. Review the scaffold files.
2. Install Electron dependencies manually only if desired.
3. Run `START_ELECTRON_DEV.cmd` after dependencies exist locally.

This is PC-only app scaffolding. It is not a keyboard package, not for keyboard load, and not for transfer media.
