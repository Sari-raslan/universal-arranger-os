# محلل SET الخاص بالمالك V31

ضع الست أو النسخة الاحتياطية يدويًا داخل `owner_set_input` ثم شغل `RUN_SET_ANALYZER_V31.cmd`.

هذا الفحص قراءة فقط. يجمع الأسماء، الأحجام، التاريخ، الهاش، الامتدادات، التخمينات، التكرارات، الأماكن الفارغة المحتملة، وملفات السامبلر المحتملة.

أي علاقة داخل ملفات ثنائية تبقى `UNKNOWN` أو `HYPOTHESIS` حتى يتم اعتماد parser لاحق.
