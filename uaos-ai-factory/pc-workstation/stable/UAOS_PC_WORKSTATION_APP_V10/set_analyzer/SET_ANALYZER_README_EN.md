# Owner SET Analyzer V31

Put the owner SET or backup manually inside `owner_set_input`, then run `RUN_SET_ANALYZER_V31.cmd`.

This scanner is read-only. It inventories file names, sizes, timestamps, hashes, extensions, category guesses, duplicate hashes, empty candidates, and sampler file candidates.

Binary relationships are marked `UNKNOWN` or `HYPOTHESIS` unless a later approved parser confirms them.
