# UAOS PC Workstation Writer V17

This local writer generates UAOS PC-format files into `writer/generated_v17_outputs`.

Safety labels: PC_ONLY, UAOS_FORMAT, TEST_UNVERIFIED, NOT_FOR_PA3X_LOAD, NOT_FOR_USB_TRANSFER, NOT_COMPATIBILITY_VERIFIED.

Generated outputs are PC-only UAOS internal files. They are not hardware files and are not for keyboard load or transfer media. The MIDI file is synthetic test material only and contains no samples.
