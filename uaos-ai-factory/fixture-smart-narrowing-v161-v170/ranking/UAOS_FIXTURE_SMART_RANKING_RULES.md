# UAOS Fixture Smart Ranking Rules

Metadata only. No content scan. No hashing of all candidates.

Priority: .STY first, .SET second, related keyboard resources lower. Trusted owner/project and backup contexts receive bonuses. Generated reports, build/cache folders, dummy/minimal/generated candidate paths, and USB review folders receive penalties. Reasonable non-zero size is preferred. Recency helps but cannot override poor context.
