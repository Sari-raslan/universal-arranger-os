# UAOS Push/Deploy Approval Gate Rules

Validator checks:
- build PASS.
- approval gate exists.
- deploy plans exist.
- release checklist exists.
- no push executed.
- no deploy executed.
- no KORG writer code or action.
- no blocked keyboard package files generated by this run.
- no USB write.
- no PA3X load.
- no KORG device compatibility claim.
- no PA3X readiness claim.
