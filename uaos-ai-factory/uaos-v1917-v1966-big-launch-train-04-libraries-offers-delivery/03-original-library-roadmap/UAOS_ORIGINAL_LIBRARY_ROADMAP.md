# UAOS Original / Future Premium Library Roadmap

Status: ORIGINAL_LIBRARY_ROADMAP_READY

Goal:
Prepare a lawful future library path that does not depend on proprietary PCM parsing, sample decoding, or keyboard binary writing.

Safe directions:
- original recordings created by owner/contracted musicians
- MIDI/performance pattern design
- synthetic/original generated sounds where rights are clear
- metadata-first catalog organization
- premium library concept documents
- future lawful licensing review

Blocked directions:
- extracting proprietary samples
- decoding PCM payloads
- cracking or bypassing protected formats
- claiming PA3X-ready output without lawful proof
