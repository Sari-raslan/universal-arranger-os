# UAOS PA3X Owner Backup Steps 002

Before UAOS reads any fixture, owner must complete these steps:

1. On PA3X, create a full backup / save current SET to USB.
2. Do not overwrite internal keyboard memory.
3. Copy USB backup to PC.
4. Place copied folder under:
   `E:\keyboard-manager-clean\uaos-ai-factory\pa3x-writer-track\owner-fixtures\pa3x-oriental-backup-001`
5. Keep original USB backup untouched.
6. UAOS reads copied folder only.

## Important
Do not provide the only copy of a PA3X backup. Keep at least one separate untouched backup outside this workspace.
