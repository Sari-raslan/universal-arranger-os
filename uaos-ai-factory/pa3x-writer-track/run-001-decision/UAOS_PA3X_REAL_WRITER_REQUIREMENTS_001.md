# UAOS PA3X Real Writer Requirements 001

A real PA3X writer requires:

- Confirmed public/owner-provided format requirements.
- No proprietary sample copying.
- No copied commercial style content.
- Binary fixture created from original safe material only.
- Offline validator for package structure.
- Owner approval before any keyboard-native file generation.
- Backup checklist completed.
- Empty USB test plan.
- Actual PA3X load-test result before compatibility claims.

Until these are satisfied, UAOS must remain dry-run / MIDI-spec only for PA3X.
