# UAOS PA3X No False Claims Policy 001

## Required wording
Use: TEST PACKAGE / UNVERIFIED, DRY-RUN, STRUCTURE TEST, MIDI-SPEC TEST.

## Forbidden wording before hardware test
Do not claim:
- PA3X-ready
- PA3X-compatible
- USB-ready for actual keyboard loading
- real keyboard output
- native PA3X writer complete

## Current truthful statement
Run 001 creates safe planning materials and a dry-run package candidate for owner review. It does not create a validated PA3X package.
