# UAOS PA3X Backup Before Test Checklist 001

Before any future PA3X load test:

- [ ] Backup current PA3X SET to a separate safe USB or computer folder.
- [ ] Verify backup can be seen outside the keyboard.
- [ ] Use a second empty USB for test material.
- [ ] Do not overwrite keyboard internal memory.
- [ ] Do not load into live performance banks.
- [ ] Keep owner-approved test notes.
- [ ] Stop immediately on any warning from the keyboard.
- [ ] Record whether PA3X accepts, rejects, or ignores the test package.
