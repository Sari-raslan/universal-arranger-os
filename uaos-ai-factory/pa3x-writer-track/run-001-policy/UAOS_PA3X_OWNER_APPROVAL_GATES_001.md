# UAOS PA3X Owner Approval Gates 001

## Gate 1 - Review dry-run package
Owner reviews README, manifest, style plan, MIDI spec, QA report, and USB instructions.

## Gate 2 - Backup before test
Owner must back up the current PA3X SET before any test.

## Gate 3 - Empty USB only
Any future test must use an empty USB prepared by the owner. Do not overwrite keyboard internal memory.

## Gate 4 - Explicit load-test approval
Load test only after owner explicitly approves using the PA3X Oriental device.

## Gate 5 - Compatibility claim
Only after a successful real PA3X load test may wording change from UNVERIFIED to hardware-tested.
