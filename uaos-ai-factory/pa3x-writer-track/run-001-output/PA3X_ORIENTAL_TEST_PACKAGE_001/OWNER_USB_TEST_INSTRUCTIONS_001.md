## Before any future hardware test
1. Read the safety policy.
2. Backup the current PA3X SET.
3. Use an empty USB only.
4. Do not overwrite keyboard internal memory.
5. Do not load anything into live performance banks.
6. Confirm this package is dry-run only and not a real keyboard-native package.
7. Stop if the keyboard shows any warning.
