# UAOS PA3X Run 011 Scope

Status: READ ONLY.

Run 011 creates a PRF parser v1 structural catalogue only. The output is non-keyboard JSON and supporting Markdown documentation.

## Allowed
- Load Run 010 stable-offset validation.
- Load Run 009 consistency results.
- Load Run 008 region catalogue.
- Load Run 007 structural map.
- Load Run 003 fixture metadata.
- Read controlled PRF structural windows only if needed.
- Emit structural catalogue JSON outside the fixture folder.

## Forbidden
- No decoded values.
- No musical meaning.
- No performance names/settings/sounds/styles inference.
- No keyboard output.
- No generated PRF/SET/STY/PRS/KST files.
- No USB write or keyboard transfer.
- No fixture modification.
