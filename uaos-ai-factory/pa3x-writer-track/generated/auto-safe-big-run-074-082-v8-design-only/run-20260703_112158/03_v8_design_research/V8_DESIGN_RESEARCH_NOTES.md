# V8 Design Research Notes

V8 should prioritize evidence discipline over candidate production. The design should describe what a future candidate would need, not create it. Key assumptions: prior V6 local artifacts are the best available research baseline; V7 was blocked; dirty tree blockers are owner-reviewed but unresolved; hardware readiness is NOT READY.

Unknowns include true PA3X PRF structure, checksum rules, accepted metadata regions, load behavior, and whether any synthetic marker strategy is useful to a real parser beyond local audit.
