# UAOS PA3X File Type Taxonomy 004

## Rollen
- SET container/folder: äußerer PA3X SET-Ordner, nur als Struktur erkannt.
- style-related: Style-Bank-Dateien aus STYLE.
- performance-related: Performance-Bank-Dateien aus PERFORM.
- pad-related: Pad-Bank-Dateien aus PAD.
- global-related: globale Setup- und Preset-Dateien.
- songbook-related: SongBook-Datenbanken und Listen.
- PCM/sample-related: nur Inventar-/Präsenzrolle, keine Sample-Dekodierung.
- MIDI-related: nur Header-/Metadatenrolle.
- metadata-report: README oder Analyseberichte.
- unknown: Datei ohne sichere Regel.

Diese Taxonomie ist eine Read-only-Klassifikation aus Run-003-Metadaten. Sie ist kein Writer und erzeugt keine Keyboard-Dateien.
