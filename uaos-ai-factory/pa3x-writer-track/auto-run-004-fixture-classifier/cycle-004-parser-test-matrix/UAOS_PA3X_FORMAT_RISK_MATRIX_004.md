|---|---:|---|---|
| Style | hoch | zentrales proprietäres Arrangement-Format | Header-/Slot-Metadaten nur nach Owner-Freigabe |

| Performance | mittel | Setup-/Verknüpfungsdaten | Strukturkarte aus Metadaten |

| SongBook | mittel | Repertoire-/Referenzdaten | reine Inventarisierung |
