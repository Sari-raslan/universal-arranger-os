# UAOS PA3X Real Writer Dependency Map 004

Ein echter Writer bleibt blockiert, bis mindestens diese Abhängigkeiten erfüllt sind:

- freigegebene Parser-Grenzen pro Formatgruppe,
- dokumentierte Slot-/Bank-Struktur,
- ungefährlicher Roundtrip-Test mit synthetischem Nicht-Keyboard-Artefakt,
- Owner-Freigabe für jeden tieferen Lesegrad,
- separate First-Output-Gate-Prüfung vor jeder nativen Ausgabe.
