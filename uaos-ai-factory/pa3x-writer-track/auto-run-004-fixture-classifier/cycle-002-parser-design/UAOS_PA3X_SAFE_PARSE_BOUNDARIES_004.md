# UAOS PA3X Safe Parse Boundaries 004

## Sicher
- Dateiliste, Größen, Hashes, Endungen, Pfade.
- KORF-Signatur als generischer Container-Hinweis.
- Parser-Spezifikation und Tests mit Metadaten.

## Blockiert
- Realer Writer.
- Native Keyboard-Ausgabe.
- Proprietäre Inhaltsdekodierung.
- Sample-Kopien oder Transfer an USB/Keyboard.
