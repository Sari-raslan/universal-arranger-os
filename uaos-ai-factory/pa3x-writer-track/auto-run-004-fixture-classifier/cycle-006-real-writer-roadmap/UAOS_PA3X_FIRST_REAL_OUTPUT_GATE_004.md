# UAOS PA3X First Real Output Gate 004

Vor der ersten nativen Keyboard-Ausgabe muss ein neuer Auftrag explizit erlauben:

- Zielformat,
- Zielordner außerhalb des Fixtures,
- Dateinamen,
- Testumfang,
- keine USB-/Keyboard-Übertragung ohne weitere Freigabe.

Run 004 gibt diesen Schritt nicht frei.
