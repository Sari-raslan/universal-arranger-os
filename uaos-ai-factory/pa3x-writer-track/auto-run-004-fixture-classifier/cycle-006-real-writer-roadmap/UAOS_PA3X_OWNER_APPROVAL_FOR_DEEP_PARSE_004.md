# UAOS PA3X Owner Approval For Deep Parse 004

Für jeden tieferen Parser muss der Owner separat freigeben:

- welche Datei-/Formatgruppe gelesen werden darf,
- wie viele Bytes gelesen werden dürfen,
- ob nur Struktur oder auch Werte analysiert werden dürfen,
- dass keine Samples kopiert oder dekodiert werden,
- dass keine Keyboard-Ausgabe erzeugt wird.
