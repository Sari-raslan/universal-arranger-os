# UAOS Original Recording Plan - Run 003

Status: SAFE PLAN ONLY

## Goal

Create a future-safe plan for original UAOS library material without copying commercial or proprietary content.

## Recording Principles

- Use original performers or original synthesis.
- Capture clean isolated notes and articulations.
- Keep performer/session metadata.
- Track consent, ownership, and usage rights.
- Store raw capture references as metadata until actual recording is approved.

## Minimum Session Metadata

- Session ID
- Date
- Instrument
- Performer or synthesis source
- Microphone or signal chain notes
- Articulation list
- Tuning reference
- Rights status
- QA notes

## Tomorrow-Safe Next Step

Implement metadata templates and validation only. Do not create audio assets in this run.
