# UAOS Library Quality Tiers - Run 003

Status: READY

## Standard

- Original or synthesized source only.
- 1-2 velocity layers.
- 1-2 round robins.
- Core articulations only.
- Suitable for prototype demos and internal review.

## Premium

- Original source capture plan.
- 3-5 velocity layers.
- 3-4 round robins.
- Extended articulations and improved transitions.
- Better metadata for arranger intelligence.

## Future Pro

- Requires owner-approved recording plan and budget.
- 5+ velocity layers where musically useful.
- Deeper round robin set.
- Advanced transitions, phrase metadata, and maqam-aware performance hints.
- No proprietary sample copying.

## Tier Gate

No tier can claim commercial readiness until source capture, QA, licensing, and owner review are complete.
