# UAOS Sample Safety Policy - Run 003

Status: ACTIVE POLICY

UAOS library development must use original recording, original synthesis, or metadata-only planning.

## Blocked

- Copying third-party commercial samples.
- Repackaging proprietary sample libraries.
- Claiming ownership of non-original audio.
- Creating restricted hardware-native output files.
- Using another vendor's library structure as a clone target.

## Allowed

- Original metadata schemas.
- Original recording plans.
- Original synthesis plans.
- Quality tier definitions.
- QA and rights tracking.

## Required QA Statement

Every library pack must state whether it contains audio, metadata only, or original source material.
