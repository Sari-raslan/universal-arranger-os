# UAOS Jobcenter Monitor Update und Redeploy

Der Monitor wurde als professioneller öffentlicher Projektmonitor aktualisiert.

## Manuelle Neuveröffentlichung

1. Open Vercel Dashboard.
2. Open project `uaos-jobcenter-monitor`.
3. Confirm Root Directory:
   `uaos-ai-factory/jobcenter-monitor-vercel-dashboard-ready`
4. Build Command:
   `echo static`
5. Output Directory:
   `public`
6. Install Command:
   `echo no-install`
7. Redeploy latest commit with cache off.
8. Verify:
   - https://uaos-jobcenter-monitor.vercel.app/jobcenter/
   - https://uaos-jobcenter-monitor.vercel.app/status/
