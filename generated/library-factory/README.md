# UAOS Library Factory

This folder contains safe demo metadata only.

It does not contain commercial samples, copied sound files, protected recordings, or a final sound library. The JSON files describe patterns, tags, and arrangement ideas for local demo use.

Safety rules:

- No protected samples are copied.
- No external files are downloaded.
- No copyrighted audio material is used.
- No final sound library claim is made.
- No real device writer is enabled.
