# UAOS V1 PLATFORM STRATEGY

## Main Vision
UAOS is not one program. It is a music platform with three product layers:

1. UAOS Sing
- For singers and normal users.
- Upload voice.
- Choose style.
- Generate full music.
- Export MP3/WAV.

2. UAOS Studio
- For creators and semi-musicians.
- Easy DAW.
- Tracks, chords, mixer, templates.
- UAOS sound library.
- MIDI/WAV export.

3. UAOS Pro Arranger
- For professional keyboard players.
- MIDI/USB connection.
- KORG/Yamaha/Roland/Ketron tools.
- Style converter.
- Set manager.
- SongBook manager.
- Sampler integration.

## V1 Launch Scope
V1 must include:
- One landing page.
- Three mode cards.
- Three separated interfaces.
- Local demo flow.
- Basic project save/load.
- MIDI device diagnostics page.
- Public pricing page.
- Download/demo page.
- Build must pass.

## V2 Scope
- Real AI voice-to-song.
- Full sampler.
- Full style conversion.
- Real KORG/Genos export.
- Cloud projects.
- Marketplace.
