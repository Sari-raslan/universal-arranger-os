# UAOS Export Foundation

Phase 7 implements an export job contract for browser-supported local rendering/download.

Supported metadata:

- full mix or selected/loop range
- track stem metadata foundation
- WAV filename metadata
- sample-rate metadata
- browser-supported bit depth
- progress and cancellation
- clipping warning
- missing asset warning
- unsupported effect warning
- local download
- no cloud upload

24-bit and 32-bit float export are not claimed unless a real implementation is added and tested.
