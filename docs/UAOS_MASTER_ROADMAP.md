# UAOS Master Roadmap

This repository is being advanced through stacked, non-deploying roadmap branches:

1. `codex/uaos-v1-production` based on `master`.
2. `codex/uaos-v2-pro-arranger` based on completed V1.
3. `codex/uaos-v3-ai-labs` based on completed V2.

## Phase Gates

- V1 must pass check, tests, build, route preservation, Electron smoke validation, bounded timeline storage, session import validation, MIDI parser tests, panic behavior, and honest feature labels before V2 begins.
- V2 must preserve V1 gates and add professional timing, multi-lane arranger, pattern editing, chord intelligence, song/setlist, scenes, device profiles, desktop offline storage, mixer/routing, and tests before V3 begins.
- V3 must preserve V1 and V2 gates and add explicitly experimental AI analysis, voice-to-MIDI, arrangement planning, rule-based generation, evaluation, licensing policy, and AI service architecture before final validation.

## Safety

No deploy command, Vercel command, production alias change, force push, or merge to `master` is part of this automated roadmap work.
