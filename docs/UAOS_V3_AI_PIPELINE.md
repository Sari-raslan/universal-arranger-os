# UAOS V3 AI Pipeline

1. Record or import melody.
2. Analyze signal with versioned confidence metadata.
3. Segment pitch contour into editable notes.
4. Quantize notes.
5. Review and correct tempo, key, chords, and sections.
6. Build a schema-validated arrangement plan.
7. Generate with the local rule-based generator unless an optional configured model is available.
8. Validate generated MIDI ranges and durations.
9. Evaluate timing, density, stuck notes, and human rating fields.
10. Export UAOS project and MIDI through the V2 editor/export foundations.
