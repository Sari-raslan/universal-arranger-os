# UAOS Sound Engine + Library

This phase adds an original UAOS sound engine and preset library.

Important:
UAOS does not copy proprietary commercial sounds, NKI libraries, Kontakt instruments, Yamaha/Korg samples, or any protected content.

UAOS creates its own original engine and supports future user-imported legal samples.

Supported now:
- Synth bass
- Piano-style synth
- Pads
- Leads
- Plucks
- Simple drums
- MIDI-triggered preview

Future:
- SF2 support
- SFZ support
- WAV multisample mapping
- velocity layers
- round robin
- real sampled piano pack
- hardware controller mapping
- marketplace sound packs
