# UAOS AI Music Pipeline

## Flow
1. Capture voice / humming / MIDI input
2. Detect pitch, rhythm, tempo, key
3. Convert melody to MIDI
4. Generate chords
5. Build arrangement
6. Render demo audio
7. Export to DAW-ready formats

## AI Tasks
- Melody cleanup
- Chord suggestion
- Style selection
- Instrument selection
- Arrangement generation
- Humanization
