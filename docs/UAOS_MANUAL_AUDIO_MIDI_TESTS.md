# UAOS Manual Audio and MIDI Tests

Run only with the intended device connected.

1. Confirm the device appears in Windows and UAOS diagnostics.
2. Test note-on and note-off without stuck notes.
3. Test reconnect after USB removal and reconnection.
4. Test panic/all-notes-off.
5. Test MIDI clock only after the user explicitly enables it.
6. Test SysEx only against documented, device-specific messages.
7. Confirm audio input and output separately.
8. Do not enable direct microphone-to-speaker monitoring by default.
9. Record detected facts separately from documented capabilities.
