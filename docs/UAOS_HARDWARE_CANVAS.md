## Future Hardware Product Lines

### UAOS Mini Controller

For beginners, laptop producers, and mobile creators.

Suggested hardware:
- 16 velocity pads
- 8 knobs
- 4 faders
- transport buttons
- USB-C MIDI
- compact body
- optional Bluetooth MIDI later

### UAOS Live Controller

For live keyboard players and performers.

Suggested hardware:
- 16 or 32 pads
- 9 faders
- 8 encoders
- arranger buttons
- fill/break/intro/ending controls
- OLED screen
- foot pedal support
- USB-C MIDI
- MIDI DIN optional

### UAOS Pro Arranger Console

For stage and studio.

Suggested hardware:
- large control surface
- performance buttons
- touch display
- style engine integration
- pro I/O
- possible onboard audio later

## Core Engineering Rule

Never hard-code UAOS to one controller.

Use a Controller Abstraction Layer.

Every controller must be driven by a mapping profile.

This allows UAOS to support:
- Akai
- Arturia
- Novation
- Korg
- Yamaha
- Native Instruments
- Generic USB MIDI
- Custom UAOS hardware
- Future devices not yet invented

## Manufacturing Plan

Do not manufacture immediately.

Correct order:

1. Make UAOS stable as MIDI brain
2. Support common MIDI controllers
3. Build mapping editor
4. Test with real musicians
5. Prototype hardware using Arduino / Teensy / Raspberry Pi Pico / ESP32
6. Design enclosure
7. Request sample from China or local manufacturer
8. Test first batch
9. Sell early hardware kits
10. Scale manufacturing
