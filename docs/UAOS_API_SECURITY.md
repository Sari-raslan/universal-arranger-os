# UAOS API Security

Phase 8 adds API safety foundations.

## Controls

- Rate limiting foundation.
- Normalized error responses.
- Opaque sessions.
- CSRF header checks for protected mutations.
- RBAC permission checks.
- Secret masking in configuration output.
- Path traversal and binary upload blocking.

## Remaining Production Work

TLS termination, production secret rotation, WAF/proxy policy, backup/restore drills and external security review remain required.
