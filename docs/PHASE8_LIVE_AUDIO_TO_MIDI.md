# UAOS Phase 8 Live Audio To MIDI Arranger

This phase adds a live feature:

Microphone audio -> pitch detection -> MIDI export -> arrangement selection.

Modes:

- full: full ready arrangement
- ork: keyboard/oriental/arranger style
- studio: computer studio production

Current level:

- live MVP
- browser microphone capture
- server-side MIDI export
- arrangement scaffold

Future production upgrades:

- YIN/CREPE pitch tracking
- polyphonic pitch detection
- onset detection
- tempo detection
- quantization
- chord recognition
- drum/bass generation
- style export
