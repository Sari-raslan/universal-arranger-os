# UAOS Complete System Architecture

UAOS is organized in three stacked layers:

- V1: browser-first runtime for audio, MIDI, sessions, timeline, arranger, backend, and desktop smoke.
- V2: professional arranger workstation modules for timing, lanes, patterns, chords, setlists, scenes, devices, mixer, and offline project storage.
- V3: experimental AI Labs for analysis, voice-to-MIDI, planning, local rule-based generation, rhythm metadata, evaluation, and safety policies.

The production build remains the active `uaos-live-clean` Vite React app.
