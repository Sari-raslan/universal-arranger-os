# UAOS Core Feature Spec

## Main Idea
User can sing, hum, play, or describe a musical idea.

UAOS converts it into:
- MIDI
- chords
- arrangement
- stems
- demo song
- DAW-ready export

## Inputs
- Voice
- Humming
- Lyrics
- MIDI controller
- Audio file
- Text prompt

## Outputs
- MIDI file
- WAV demo
- Stems
- Chord chart
- Arrangement plan
- Social demo video
