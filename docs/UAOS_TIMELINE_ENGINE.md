# UAOS Timeline Engine

The Phase 7 timeline engine supports PPQ musical time, seconds conversion, tempo maps, time-signature metadata, playhead metadata, selection, loop, punch, markers, snapping, zoom, scrolling, and deterministic clip operations.

Supported clip operations:

- placement
- movement
- resize
- split
- duplicate
- delete through UI state
- overlap rejection option
- deterministic ordering
- validation of invalid edits

Timeline calculations are testable without React.
