# UAOS Recording System

Phase 7 adds local audio and MIDI recording foundations.

Audio recording supports input metadata, record arm, monitoring metadata, input level/clipping metadata, count-in/punch metadata, local Blob URL metadata, take metadata, failed-record cleanup, permission/unsupported states, waveform extraction foundation, local download metadata, and clip creation.

MIDI recording supports note-on/off capture, CC/pitch/sustain event storage contracts, channel filtering, timestamp normalization, quantized/unquantized metadata, loop recording foundation, overdub/replace metadata, panic, stuck-note protection, disconnect fallback, and clip creation.

No recordings are uploaded to cloud automatically.
