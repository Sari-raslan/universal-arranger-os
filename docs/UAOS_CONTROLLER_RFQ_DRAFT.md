# UAOS MIDI Controller RFQ Draft

## Product

UAOS Mini Controller

## Purpose

A USB MIDI controller designed to work as a hardware body for the UAOS Brain software.

## Required Features

- USB-C MIDI class compliant
- 16 velocity-sensitive RGB pads
- 8 rotary encoders
- 4 faders
- 8 function buttons
- transport buttons
- firmware update support
- Windows/macOS/Android compatibility
- optional BLE MIDI
- optional OLED screen

## Firmware Requirements

- MIDI 1.0 class compliant
- stable USB device name
- configurable CC/note mapping
- factory reset mode
- firmware update method
- no proprietary driver required
