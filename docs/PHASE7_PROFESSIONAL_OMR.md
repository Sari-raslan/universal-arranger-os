# UAOS Phase 7 Professional OMR Engine

This phase adds the architecture for a professional OMR pipeline:

- Computer Vision preprocessing
- Staff segmentation
- Symbol classification
- MusicXML generation
- MIDI export
- Rhythm reconstruction
- Beam/slur/tie relation detection
- Chord separation
- Voice separation

Current level: scaffold / beta architecture.

To become fully professional, UAOS needs trained ML models and a labeled sheet-music dataset.
