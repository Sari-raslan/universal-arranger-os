# UAOS V3 User Workflow

1. Open `#/ai`.
2. Review the experimental label and processing location.
3. Analyze or import a melody source.
4. Review notes and confidence.
5. Correct tempo, key, chords, and sections.
6. Select density, genre, lanes, and constraints.
7. Generate with the local rule-based generator.
8. Regenerate one lane or region without replacing other lanes.
9. Edit the result in the V2 pattern editor.
10. Export UAOS project and MIDI.
