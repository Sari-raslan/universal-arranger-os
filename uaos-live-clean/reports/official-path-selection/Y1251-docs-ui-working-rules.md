# Docs/UI Path Working Rules

## Path

PATH-DOCS-UI

## Allowed File Types

- .html
- .json
- .md
- .txt

## Allowed Work

- review page polish
- documentation refinement
- status explanation
- governance index improvement
- handover clarity
- non-operational reports

## Forbidden Work

- runtime features
- writer implementation
- binary exporters
- keyboard output
- production parsers
- deployment scripts
- fixture access
- App.jsx edits

## Stop Conditions

- Any request to create real output
- Any request to implement writer
- Any request to touch fixtures
- Any request to deploy
- Any request to modify App.jsx
- Any request to introduce operational code
