UAOS Agent Command Center

Safe local task center for all desktop agents. Unknown agents are not executed automatically.

QA Agent

Run all local QA and final gate.

node scripts/qa/verify-local-music-engine-all.mjs node scripts/qa/final-local-music-engine-gate.mjs

Scanner Agent

Metadata-only scanner with approval JSON.

node uaos-live-clean/src/uaos-local-music-engine/real-limited-scanner-v1/realLimitedScannerCli.mjs --approve-real-limited-scanner-v1 --approval-json ".\approval-decision.json" --folder "D:\Music"

Pipeline Agent

Import scanner report to final workspace.

Get-Content ".\uaos-real-limited-scanner-v1-report.json" -Raw | node uaos-live-clean/src/uaos-local-music-engine/real-scanner-pipeline-import/realScannerPipelineImportCli.mjs --approve-import-real-scanner-report
