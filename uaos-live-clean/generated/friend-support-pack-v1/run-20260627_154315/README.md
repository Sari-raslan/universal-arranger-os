# UAOS Friend Support Pack V1

## عربي

هذه نسخة مراجعة خاصة من مشروع **UAOS - Universal Arranger OS** موجهة لصديق موثوق حتى يفهم المشروع بسرعة، ويرى لماذا أحتاج دعمًا عمليًا الآن.

UAOS هو نموذج محلي لبرنامج موسيقي يساعد على تحويل فكرة أغنية إلى مشروع منظم: أقسام موسيقية، كوردات، مسارات، معاينة، وحزمة تصدير آمنة للمراجعة.

ما تم إنجازه:

- واجهة محلية تعمل كبرنامج موسيقي.
- Demo Mode للشرح السريع.
- إدارة مشاريع محلية داخل المتصفح.
- توليد ترتيب موسيقي مبدئي مع sections/tracks/chords.
- تصدير ملفات JSON آمنة للمراجعة.
- لا يوجد نشر عام جديد.
- لا يوجد device writer أو إخراج ملفات كيبورد حقيقية.

الدعم المطلوب الآن:

أحتاج دعمًا ماليًا عمليًا لشراء أو تمويل لابتوب/جهاز عمل أقوى. الجهاز الأفضل سيساعدني في التطوير، الاختبار، العرض، وتجهيز نسخ أوضح للمراجعة والدعم.

## English

This is a private review pack for **UAOS - Universal Arranger OS**, prepared for a trusted friend to quickly understand the project and the current support need.

UAOS is a local music workstation prototype that turns a song idea into a structured arranger-style project: sections, chords, tracks, preview, and safe review exports.

Current status:

- Local app interface works as a music workstation prototype.
- Demo Mode explains the project quickly.
- Local browser project management is available.
- Arrangement generation creates sections/tracks/chords.
- Safe JSON review exports are available.
- No new public publishing.
- No device writer or real keyboard-file output.

Current support need:

The most useful support right now is funding for a stronger laptop/work machine. A better machine will help continue development, testing, demos, and private review preparation.
